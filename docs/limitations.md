# 支持范围与限制

[文档首页](README.md) · [使用指南](usage.md) · [兼容性与验证](compatibility.md)

| 类型 | 支持 | 主要限制 |
| --- | --- | --- |
| Markdown | 阅读、块编辑、源码、公式、图表、本地图片 | UTF-8；最多 8 MB；保存已有 .md/.markdown，不新建文档 |
| 图片 | PNG/JPEG/GIF/WebP/SVG/BMP/ICO/AVIF | 独立图片 40 MB；解码能力取决于宿主浏览器 |
| Markdown 嵌图 | 相对/绝对/file URI/引用式/Obsidian | 本地图片；单张 20 MB、单批 32 MB；拒绝网络共享 |
| Mermaid | 严格模式，缩放、拖动 | 20 图/篇；单图 2 万字符、200 条边；总计 10 万字符；禁用图内配置与交互链接 |
| PDF | 翻页、缩放、书签、文字搜索 | 可选依赖；64 MB、10000 页；图片式展示，无选文/OCR/表单/批注 |
| 代码与文本 | 离线高亮/原文 | UTF-8；8 MB；不执行；Notebook 展示 JSON 原文 |
| CSV/TSV | 分页、筛选、表头切换、原文 | 最多 5000 行、100 列、10 万单元格、100 万字符；超限提示 |
| Office/音视频等 | 文件树可显示图标，交给宿主打开 | 不代表支持在本页渲染 |

## 文件访问

宿主所选文件或用户选定项目建立锚点。构建时配置 `--allowed-root` 后，文件、目录、嵌图及保存限定于该目录，解析后越界的路径会被拒绝；这是应用层检查，不是操作系统沙箱。未配置时仍采用同一磁盘边界，Linux 上范围可能很广。目录按层载入，最多列出 500 项；筛选仅查已加载名称。用户可在配置的允许范围内返回上级；未配置目录边界时可浏览同盘其他目录。UNC/网络共享不支持。新建文件夹有额外的名称、同名和链接路径检查。

项目自动识别依赖宿主提供的对话标识和本机只读状态结构；结构变化时可能失效，桌面环境可手动选择文件夹；无图形桌面的 SSH 环境使用 `--project-root` 配置明确的后备根目录，并通过 `--headless` 禁用 Tkinter。不修改宿主内部程序。

## 编辑

点击前固定块和文字位置，再补偿布局变化。普通文字和代码可以按点击点定位；图片、公式等没有一一对应的可见字符时，可能只能从块开头编辑。源码与排版尺寸不同，块内部会重新布局；目标是避免误入其他块和无关滚动，不能保证所有混排内容像素完全不变。

保存为显式操作。原文件 SHA-256 不匹配时拒绝覆盖。保留 UTF-8 BOM 与统一 CRLF；非 UTF-8 文档不保存。备份默认保存在用户主目录的 `.codex/backups/file-preview/`；没有自动清理策略。

草稿存储可被宿主禁用/清空，不能当作永久备份。刷新、切文件和切根目录时有未保存提示；关闭标签仍请先保存。

## 与原生查看器的区别

插件有自己的文件树和批注界面，不能直接改造原生查看器。顶部宿主标签通常显示插件名；文档名在插件工具栏显示。双击打开行为由宿主决定，新建或复用标签不能强制保证。

选区引用/批注加入的是聊天草稿，支持程度依赖宿主；不等同于原生可逐条编辑的评论卡片。编号气泡和批注队列只在当前标签内存中保留。

## 测试范围

Windows 是主要桌面验证环境；Linux/Windows 自动回归已包含 Python、Node 和 PDF。Linux/SSH 后端也有真实服务检查，但桌面端远程发现、菜单和实际渲染仍待人工验收。Node/Python 回归和本机回环 UI 宿主可以复现逻辑，不证明每个桌面版本的权限、菜单或元数据注入都兼容。欢迎在 issue 中提供宿主版本和虚构的最小复现文件。
