## 第一次使用

1. 按环境选择 [Windows 安装](installation.md) 或 [Linux / SSH 安装](linux-ssh-installation.md)。
2. 阅读[使用指南](usage.md)，完成打开、编辑、保存的一次完整操作。
3. 用 [Atlas Lab 演示项目](../examples/atlas-lab/README.md) 体验其他格式。
