# 刷新文件与重载插件

| 入口 | 用途 |
| --- | --- |
| 顶部 ↻「刷新文件」 | 重新读取当前文件，查看外部修改后的内容。 |
| 文件树 ↻「刷新文件树」 | 更新目录列表，包括已展开的分支。 |
| 顶部「重载插件」 | 在当前标签使用本机已安装的新界面和兼容的后台。 |

安装新版后点击「重载插件」。成功时会显示版本号。如果同时切换了后台，还会显示「后台已更新」。

重载会恢复当前文件、项目或 SSH 会话、文件树根目录、展开分支、筛选条件、目录宽度、阅读位置、字号和暂存批注。Markdown 有未保存的改动时，可以保存、放弃或者取消重载。文件选择、保存和传输结束后才能切换。

从 1.13.x 升级时，需要完整退出并重开 Codex 一次，让它加载新版启动入口。之后，工具和资源注册兼容的后台更新可直接在当前标签生效。Codex 连接配置、启动入口或工具和资源注册变化时，需要重新建立插件连接。

重载只读取本机已完成校验的安装包。后台更新时，原连接保持打开。候选进程通过版本、工具和资源注册检查并接收会话状态后才接管请求。候选进程启动或检查失败时，原进程继续工作，界面显示错误。

构建在最后发布 `ui-build.json`，记录界面哈希和后台指纹。发布时更新整个构建包，重载会校验安装文件和后台副本。
