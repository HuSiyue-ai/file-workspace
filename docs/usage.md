# 使用指南

## 打开第一个文件

安装并重启桌面端后，在右侧打开 Markdown，从文件标签的“打开”菜单选择 **file-workspace**。之后可以一直留在同一个工作台，使用文件树切换其他文档、图片和数据。

宿主若提供新标签页的插件入口，可直接打开空白工作台。项目自动识别需要宿主提供当前聊天标识和可解析的状态；Linux/SSH 环境应先配置[明确的项目入口](linux-ssh-installation.md#3-在服务器构建)。

## 文件树与大纲

| 操作 | 结果 |
| :--- | :--- |
| 单击文件 | 在当前预览页切换内容 |
| 单击文件夹 / 双击文件夹 | 展开或收起 / 进入该目录 |
| `↑` / 定位按钮 | 返回允许范围内的上级 / 定位当前文件 |
| 筛选框 | 筛选已经载入的名称，不扫描整个磁盘 |
| 拖动分隔边界 | 调整文件树宽度 |
| 点击“大纲” | 按 Markdown 标题定位章节 |
| 右键文件 | 复制路径、加入聊天或交给宿主打开 |
| 右键文件夹 | 创建一个子文件夹，不覆盖同名内容 |

文件树按层载入，单层最多 500 项。双击文件交给宿主处理，是否新建或复用标签由宿主决定。受限根目录、符号链接和格式规则见[支持范围](limitations.md)。

## 阅读、编辑与源码

- **阅读**：正文保持排版，适合浏览、选文和添加评论。
- **编辑**：点击需要修改的段落、列表或代码块，展开该块的 Markdown 源码；其他块继续显示排版结果。
- **源码**：编辑整篇 Markdown，适合调整结构或跨段修改。

只有已有的 UTF-8 `.md` / `.markdown` 可编辑。代码文件、CSV/TSV、图片和 PDF 提供只读预览。

## 保存与冲突

点击“保存”或按 `Ctrl+S` 才写回文件。保存前检查读取时的 SHA-256 版本，并备份原文；外部程序修改了文件时，会阻止覆盖。

冲突发生后，先复制保留自己的修改，再刷新读取最新文件并重新编辑。不要将未保存的草稿当作持久备份。切文件或刷新前处理未保存提示，关闭标签前主动保存。

第一次操作请复制一份[示例笔记](../examples/atlas-lab/notes/methods.md)，修改、保存、刷新后检查磁盘内容，避免用唯一文档做试验。

## 选区评论与聊天草稿

1. 选中正文，点击“评论…”，输入问题或修改要求。
2. 点击确认，段落旁会保留编号气泡；可继续收集其他引用。
3. 打开顶部“批注”汇总，修改或移除条目。
4. 点击“加入聊天草稿”，检查引用和评论，再由你决定是否发送。

评论仅保留在当前标签内存中，关闭标签会清除；不会写进 Markdown，也不是宿主原生的永久评论。聊天草稿入口依赖宿主支持。
