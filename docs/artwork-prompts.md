## README concept cover

```text
Use case: ads-marketing / stylized-concept. Asset type: premium open source software GitHub README cover, very wide landscape about 2.3:1. Create a beautifully art-directed editorial product illustration for 'file-workspace', a local file workspace inside a coding assistant's sidebar. This is a CONCEPTUAL COVER, NOT a fake screenshot. Sophisticated restrained palette: warm near-white #f5f6f4 background with subtle fine paper grain, deep navy typography, electric cobalt #2563eb, pale glacier blue, tiny mint accents. Left 45%: lots of negative space, large exceptionally crisp editorial sans-serif exact title 'file-workspace' on one line, smaller exact subtitle 'Read. Edit. Explore.' beneath, tiny quiet label 'A LOCAL WORKSPACE FOR CODEX'. Right 55%: beautifully composed high-end 3D/isometric stack of 4 thin frosted-glass and off-white paper panels representing a document, folder tree, mathematical formula and a mountain image tile; connected in a tidy architectural arrangement with tasteful shadows, minimal blue wireframe connectors and a warm soft studio light. A cobalt right-side vertical file tree rail visible conceptually. One small clear mathematical E = mc² on one sheet, simple horizontal text-like rules, no illegible pseudo UI. Deliberate composition with depth and remarkable material quality. Clean professional European design magazine meets developer tools. No browser chrome, no people, no mascots, no real company logos, no badges, no gradients that obscure text, no extra slogans, no watermark. Keep all title and art well away from image edges. The composition should look designed specifically for a refined open-source file reader/editor, not a generic SaaS illustration.
```
