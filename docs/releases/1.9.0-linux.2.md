# file-workspace 1.9.0-linux.2

This Linux / SSH preview incorporates the new-conversation launcher fix verified
in Windows-local version 1.8.3, while preserving the Linux configuration and access boundaries.

- Empty desktop launchers can opt into a one-shot selected-project fallback when
  the host has not created a persistent conversation context.
- Delayed conversation context is retried for a bounded period. Opening a file,
  choosing a folder or closing the viewer cancels pending startup work.
- Linux / SSH continues to prefer server conversation context and explicitly
  configured project roots. `CODEX_HOME`, allowed roots and headless mode remain supported.

## Updating an existing server installation

Preserve local changes and `.runtime/server-env.json`, pull the repository with
`git pull --ff-only`, rebuild using the original server Python environment, and
run `codex plugin add markdown-math-preview@markdown-preview-local`. Reconnect the
desktop SSH project and reopen the preview after the backend reloads.

See the [Linux / SSH installation guide](../linux-ssh-installation.en.md).
These are source-only archives; build on the target machine. This release does
not deploy updates to a server automatically. Desktop-selected project state is
not transmitted to SSH hosts; actual SSH menu discovery and rendering still
require verification in the user's desktop environment.
