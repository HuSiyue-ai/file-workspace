# file-workspace v1.9.0-linux.1 · Linux / SSH 预览版

在 Linux 服务器上运行 file-workspace，通过 Codex 桌面端连接 SSH 项目，使用项目文件树浏览资料和编辑 Markdown。**服务器后端已验证；桌面端远程入口和实际右侧渲染仍需按所用版本验收。**

[下载源码包](https://github.com/HuSiyue-ai/file-workspace/releases/download/v1.9.0-linux.1/file-workspace-1.9.0-linux.1-linux-source.tar.gz) · [SHA-256 校验文件](https://github.com/HuSiyue-ai/file-workspace/releases/download/v1.9.0-linux.1/SHA256SUMS.txt) · [Linux 安装指南](https://github.com/HuSiyue-ai/file-workspace/blob/main/docs/linux-ssh-installation.md) · [English guide](https://github.com/HuSiyue-ai/file-workspace/blob/main/docs/linux-ssh-installation.en.md)

## 这个版本带来什么

| 改进 | 使用时的变化 |
| :--- | :--- |
| 无图形桌面运行 | `--headless` 禁用 Tkinter，使用项目文件树打开内容 |
| 明确的项目入口 | `--project-root` 在宿主元数据不可用时提供后备目录 |
| 可选访问边界 | `--allowed-root` 限定文件、目录、嵌图与保存范围，拒绝解析后越界的路径 |
| 本机配置复用 | 在目标服务器构建，记录其 Python 和插件路径，后续重建复用项目设置 |
| 跨平台检查 | 修正 Windows 专用测试路径，增加 Linux/Windows 自动回归 |

安装与卸载继续使用内部标识 `markdown-math-preview@markdown-preview-local`；应用显示名为 **file-workspace**。

## 安装顺序

1. 准备 **Python 3.12+** 与支持 `codex plugin` 的 CLI；以 SSH 登录用户操作，无需 `sudo`。
2. 下载源码包和校验文件，在同一目录执行 `sha256sum -c SHA256SUMS.txt`，确认 `OK` 后解压到长期保留的新目录。
3. 进入源码目录，创建环境并构建。将下面的示例路径替换为已有服务器项目的绝对路径：

```bash
python3.12 -m venv .venv
.venv/bin/python build.py \
  --project-root /absolute/path/to/project \
  --allowed-root /absolute/path/to/project \
  --headless
.venv/bin/python doctor.py
codex plugin marketplace add .
codex plugin add markdown-math-preview@markdown-preview-local
```

4. 保存工作，完整退出电脑上的 Codex（含托盘），重连同一个 SSH 项目并新建聊天。
5. 在右侧打开服务器 Markdown，从文件标签的“打开”菜单选择 **file-workspace**。用临时测试文档检查正文、公式、本地图片与保存。[验收步骤](https://github.com/HuSiyue-ai/file-workspace/blob/main/docs/linux-ssh-installation.md#5-在电脑桌面端验收)

## 附件包含什么

- `file-workspace-1.9.0-linux.1-linux-source.tar.gz`：源码、离线 vendor 资源、许可证和示例。
- `SHA256SUMS.txt`：上述源码包的 SHA-256 校验值。

源码包不含 Python、服务器路径配置、Codex 配置备份或已生成插件。**必须在目标服务器重新构建**。后续文档优化不会移动这个版本的标签或替换已验证的附件；最新使用说明通过上方文档链接获取。
