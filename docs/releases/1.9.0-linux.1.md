# file-workspace v1.9.0-linux.1 — Linux / SSH preview

首个 Linux/SSH 预览发布版。继续沿用插件内部标识 `markdown-math-preview@markdown-preview-local`，显示名为 **file-workspace**。

## 新增与修复

- 在服务器本地构建；支持 `--project-root`、`--allowed-root`、`--headless`，并保存本机配置供后续重建。
- 优先识别宿主聊天对应的服务器项目；缺少元数据时使用明确配置的项目根目录，并遵循 `CODEX_HOME`。
- 无桌面服务器可禁用 Tkinter；从项目文件树浏览、预览和编辑 Markdown。
- 可配置目录边界，拒绝越界路径与符号链接，覆盖文件、目录、嵌图和保存操作。
- 修复测试及调试入口中的 Windows 专用路径，增加 Linux/Windows 回归矩阵。
- 增加独立版本文件，统一服务协议与插件清单版本。

## 安装

需要 Python **3.12+**。下载 `file-workspace-1.9.0-linux.1-linux-source.tar.gz`，先用同页 `SHA256SUMS.txt` 校验，再在长期保留的目录解压。进入源码目录，以 SSH 登录用户执行：

```bash
python3.12 -m venv .venv
.venv/bin/python build.py \
  --project-root /absolute/path/to/project \
  --allowed-root /absolute/path/to/project \
  --headless
.venv/bin/python doctor.py
codex plugin marketplace add .
codex plugin add markdown-math-preview@markdown-preview-local
```

用现有的服务器项目绝对路径替换示例。完整退出桌面端，再重新连接同一个 SSH 项目并新建聊天；从右侧文件标签的“打开”菜单选择 **file-workspace**。

源码包包含离线 vendor 资源和许可证，不包含 Python、服务器路径配置、Codex 配置备份或已生成的插件。必须在目标服务器重新构建。

## 验证边界

- Linux 服务器真实 MCP stdio 服务、离线 HTML 资源、当前聊天项目目录、Unicode/空格路径 Markdown 与 SVG/PNG、临时文档保存/备份/冲突保护已经实测。
- Linux/Windows 自动回归（含可选 PDF）是发布工作流的前置条件；可在仓库 Actions 查看结果。
- **实际桌面端 SSH 插件发现、右侧菜单、图片/公式视觉渲染及按钮保存仍需要用户在所用桌面版本验收。服务器安装成功或 CI 通过不能代替这一步。**
- 配置的目录边界是应用层检查，不是操作系统沙箱。

English: This is a Linux/SSH preview, not a claim of end-to-end desktop compatibility. Rebuild on the target host with Python 3.12+, configure an explicit project/allowed root, and validate the desktop SSH file entrypoint manually.

See [Linux/SSH installation](https://github.com/HuSiyue-ai/file-workspace/blob/v1.9.0-linux.1/docs/linux-ssh-installation.md) and [general installation](https://github.com/HuSiyue-ai/file-workspace/blob/v1.9.0-linux.1/docs/installation.md).
