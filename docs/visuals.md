# 展示图片与来源

[文档首页](README.md) · [功能图览](features.md)

首页使用轻量的 SVG 字标与一张真实块编辑近景；完整截图保留在功能图览中。概念插画作为独立素材保留，和真实截图明确区分。所有示例均来自虚构的 [Atlas Lab 项目](../examples/atlas-lab/README.md)。

## 清晰度与展示尺寸

旧版浏览器截图接口实际输出 JPEG，部分资源却使用了 `.png` 后缀；这不代表它们是无损 PNG。当前文档不再引用这些旧图，新的截图按实际编码使用 `.jpg`，没有通过改扩展名假装提高画质。

截图通过隔离演示宿主将真实查看器按 **2 倍显示比例**渲染，再直接采集功能近景。它不是把旧图插值放大，也没有进行锐化、文字修补或 AI 界面重绘。PDF 页额外按输出像素需求采样，避免先生成小位图再放大。浏览器接口仍提供压缩 JPEG，因此不宣称截图本身无损；流程图直接提取为查看器生成的原生 SVG，保留矢量文字与线条。

- 文件树与大纲以约 **340 px** 宽展示，避免整屏空白挤小目录文字。
- 大部分功能图以 **600 px** 宽展示，代码特写为 **560 px**。
- 首页字标与块编辑示例按 **720 px** 宽展示；窄屏保持图片等比缩放。
- `images/wordmark.svg` 为代码绘制的矢量字标，不是界面截图，也不含外部字体或脚本。
- 每张图增加独立的浅灰蓝宽框、内边线与留白，和正文白底明确分开。详细图览延用原有展示外框，不重绘截图内容。

## 宽框与原图

`images/showcase/frames/` 中的 SVG 是代码生成的展示外框。截图以原始 JPEG 字节嵌入，封面以原始 WebP 字节嵌入，不重复编码；流程图则保留原生 SVG 内容。边框只负责构图和分隔，不修改功能画面。

点击配图会打开 `images/showcase/retina/` 中对应的原始资源；封面打开原始 WebP。原生像素尺寸可在原图中进一步查看。旧版图片保留在 Git 历史与原有目录中，但不参与本版 README 展示。

## AI 插画

- `images/showcase/cover.webp`：内置 ImageGen 生成的概念封面，表达文件、目录、公式和图片围绕工作台组织的想法，不是软件实际截图。
- `examples/atlas-lab/figures/alpine-lake.webp`：内置 ImageGen 生成的山水样图，仅用于图片查看与缩放演示，不宣称拍摄于真实地点。

两项插画以无损 WebP 保存，原始分辨率不变。完整提示词见 [artwork-prompts.md](artwork-prompts.md)。
