# file-workspace

Markdown、图片和文本共用一个窗口与文件树。

## Markdown editing

模式选择“编辑”后，点击本段可编辑源文，其他段落继续保持渲染。
点击外部恢复排版；保存或 Ctrl+S 才写回文件。

行内公式 $E=mc^2$，以及分式 $\frac{a+b}{c+d}$。

## Image preview

![Sample image](sample.png)

在文件树中单击 sample.png，即可使用滚轮缩放、拖动、适应窗口和原始大小。

## File tree

- 单击文件：在当前页切换。
- 双击文件：交给应用打开。
- 单击文件夹：展开、收起。
- 双击文件夹：进入；↑ 返回上级。
- 右键文件：复制路径、添加到聊天。
